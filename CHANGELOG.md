# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - Unreleased

### Added

- Configurable minimum and maximum typing speed (ms per character)
- Configurable pause duration between phrases (ms)
- Optional letter-by-letter erasure before the next phrase is typed

## [1.0.0] - 2019-06-05

### Added

- Animated search field placeholder using [Theater.js](https://github.com/nicktindall/theaterjs)
- Configurable CSS selector for the search input element
- Configurable list of hint phrases (one per line)
- Plugin disables itself automatically when the phrase list is empty
- Compatible with the Search Autocomplete plugin
