# Динамические подсказки поиска — плагин для Shop-Script

[English version](README.en.md)

Плагин анимирует текст-заполнитель (placeholder) строки поиска в вашем интернет-магазине. Фразы появляются одна за другой как будто их печатает живой человек — это привлекает внимание покупателей к поиску и демонстрирует примеры правильных запросов.

## Требования

- PHP 7.4 или выше
- Webasyst Shop-Script

## Настройки

| Параметр | Описание |
|---|---|
| **Селектор поля поиска** | CSS-селектор элемента `<input>`, у которого меняется атрибут `placeholder`. По умолчанию: `input[name=query]`. Если в вашей теме селектор другой — укажите его здесь. |
| **Список заменителей** | Фразы-подсказки, по одной на строку. Плагин последовательно «печатает» их в поле поиска и повторяет цикл. Если поле оставить пустым — плагин отключится. |
| **Минимальная скорость набора** | Минимальная задержка между символами в миллисекундах. Больше значение — медленнее набор. По умолчанию: `80`. |
| **Максимальная скорость набора** | Максимальная задержка между символами в миллисекундах. По умолчанию: `450`. |
| **Пауза между подсказками** | Задержка после полного набора слова перед переходом к следующей фразе, мс. По умолчанию: `1000`. |
| **Стирать посимвольно** | Если включено, текущая подсказка стирается посимвольно перед показом следующей. По умолчанию выключено. |

## Как это работает

Плагин добавляет в тег `<head>` страниц магазина скрипт на основе библиотеки [Theater.js](https://github.com/nicktindall/theaterjs). Скрипт находит поля поиска по указанному селектору и анимирует их placeholder, циклически воспроизводя список заданных фраз.

## Совместимость

Протестирован с основными темами дизайна Shop-Script и совместим с плагином «Автозаполнение поиска». Корректная работа с кастомными темами и нестандартными плагинами поиска не гарантируется.
